# Homebrew Tap for TrimWM

Install [TrimWM](https://github.com/cornz/TrimWM):

```sh
brew install --cask cornz/tap/trimwm
```

Upgrade:

```sh
brew upgrade --cask trimwm
```

Uninstall while keeping the configuration:

```sh
brew uninstall --cask trimwm
```

Remove the app and its configuration:

```sh
brew uninstall --cask --zap trimwm
```
